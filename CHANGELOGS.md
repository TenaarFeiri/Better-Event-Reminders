# 0.2.0

### New Features
- There is now a button on the reminder frame which opens your map and sets the waypoint to the event.
- New option added to close the reminder frame by clicking anywhere on it.
- Added an X to the frame so the user can quickly close it.

### Improvements
- The alert frame now has a subtle glow animation when it appears.
- The alert frame now fades out when it is closed.
